# 모두의 창업 2차 기술 증거

검증일: 2026-09-15

## 현재 구현

- Android AccessibilityService로 코레일톡 화면의 접근성 노드를 읽는다.
- 화면 가장자리의 큐 버튼을 사용자가 누른 뒤 음성 요청을 받는다.
- 다음에 직접 누를 한 영역을 강조하고 나머지 영역을 마스킹한다.
- 역 검색어 입력 외 주요 선택과 탭은 사용자가 직접 수행한다.
- 로그인·개인정보 화면에서는 안내를 진행하지 않고, 결제 진입 위치를 알려준 뒤 중단한다.
- 화면·음성 원문은 저장하거나 개발자 서버로 전송하지 않는다.

## 검증 결과

```text
./gradlew test :app:detekt lint
BUILD SUCCESSFUL
JVM unit tests: 94
Failures: 0
Errors: 0
```

단위 테스트는 명령 해석, 화면 후보 점수화, 상태 전이, 열차 후보 선택, 오버레이 위치 계산과 민감 화면 중단 규칙을 포함한다. 이 결과는 실제 코레일+ 최신 화면 전체나 65세 이상 사용자의 과업 성공을 증명하지 않는다.

## Play 접근성 정책 준비

- 앱 내부 별도 접근성 정보 고지
- 동의·거부·철회 흐름
- 마이크 권한을 설명 뒤 사용자 행동으로 요청
- 개인정보 처리방침과 공개 HTTPS 주소
- AccessibilityService 신고 초안과 실제 기기 영상 대본
- 사용자 대신 예매·결제하지 않는 안전 경계

## 증거 경계

- 현재 제출 AAB와 소스의 전체 데모 조건은 `진주→서울·어른 2명·어린이 1명`이다.
- 임의의 전국 노선·날짜·인원, 방언과 여러 앱 지원은 구현 전 계획이다.
- Play 승인, 65세 이상 사용자 결과, 코레일 제휴와 기업 매출은 아직 없다.
