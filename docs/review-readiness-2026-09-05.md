# CUEE 심사 준비 및 사용자 테스트 점검 — 2026-09-05

## 판단

현재 증거로 프로덕션 심사 통과를 예측하기에는 부족하다. 코드 빌드 성공과 실제 사용자 검증, Play Console의 출시 자격은 서로 다른 확인 항목이다. 이번에는 앱 코드를 수정하거나 Console에 제출하지 않았다.

## 이번 확인 결과

- `./gradlew test lint bundleRelease`: 성공. 대부분 UP-TO-DATE이며 기존 검사 결과를 재사용했다.
- 개인정보 처리방침 `https://gyutaetae.github.io/cuee/privacy-policy/`: HTTP 200.
- API 36 대상, 릴리스 축소 및 서명 구성 존재.
- Android 12 이상 `res/xml-v31/cue_accessibility_service.xml`에 `isAccessibilityTool=true`가 있음. 기본 `res/xml/` 파일만 보면 누락으로 오판할 수 있다.
- 앱 내 고지·동의·거부·철회와 Android 음성 인식 제공자의 외부 처리 가능성 고지가 존재한다.
- 실제 코레일+ 전체 흐름은 이번에 검증하지 못했다. `adb devices -l`에 연결 기기가 없었다.
- 저장소 모집 문서의 참여 방법과 Play 옵트인 링크는 빈칸이다. Console의 실제 트랙·신원 확인·테스터 수·참여 기간은 미확인이다.
- Reddit 로그인 상태, r/AndroidClosedTesting 작성 화면 및 운영자 안내를 확인했다. Google/Google Groups 외 외부 링크 금지. 입력 시 컴퓨터 유즈 오류(clipboard timeout, noWindowsAvailable)가 발생해 게시하지 못했다.

## 제출 전 우선순위

1. **실제 사용성**: 현재 배포할 릴리스와 최신 코레일+ 조합으로 처음 설정부터 진주→서울 조회 및 안전 종료까지 확인한다. 음성 인식, 잘못된 강조, 권한 거절·철회, 큰 글꼴을 포함한다. 이전 mock 성공을 실서비스 증거로 제출하지 않는다.
2. **접근성 도구 자격**: 인지·학습 장애 사용자를 지원하는 것이 실제 주목적인지, 대상 사용자에게 어떤 어려움을 해결하는지 검증한다. 고령 또는 디지털 사용 미숙만으로 자격이 자동 성립하지 않는다. 자격이 맞지 않으면 일반 앱의 AccessibilityService 고지·동의·신고 경로를 적용한다. 심사만을 위해 대상 사용자나 연구 결과를 꾸미지 않는다.
3. **제출물 일치**: 앱, 스토어 설명, 접근성 신고, Data safety와 영상을 동일 버전에 맞춘다. 스토어 초안은 열차 선택·예매 화면에서 멈춘다고 설명하지만 데모 문서에는 해당 화면 안내가 있어 종료 경계를 확인해야 한다. 음성 제공자의 외부 처리 가능성을 포함해 데이터 흐름을 판단한다.
4. **심사용 재현 절차**: 별도의 소명 영상에 첫 실행, 고지 전문, 거부, 동의와 설정, 실제 기능, 종료와 철회를 담는다. 코레일+ 설치·언어·로그인 등 필요한 전제와 심사자가 따라 할 절차를 App access에 설명한다.
5. **비공개 테스트**: 계정이 2023-11-13 이후 생성된 개인 계정이면 최소 12명이 14일 연속 옵트인을 유지한 뒤 프로덕션 액세스를 신청한다. 형식적인 설치만이 아니라 실제 사용·피드백·수정 내용을 기록한다. 비공개 테스트 배포 심사와 이후 프로덕션 액세스/출시 심사를 구분한다.

## 실제 사용자 테스트 운영안

운영 제안이며 Google의 추가 의무 조건은 아니다.

- 모집: 이탈을 고려해 15명 내외. 한국어와 코레일+를 사용할 수 있는 Android 사용자. 이 중 3~5명은 실제 대상 사용자 또는 사용을 돕는 보호자와 사용성 세션을 진행한다.
- 일정: 첫날 설치·고지·권한 설정, 중간 핵심 조회 흐름, 마지막 수정 버전 재검증. 14일 연속 옵트인은 별도로 확인한다.
- 과제: 도움 없이 동의 설명 이해 → 큐 켜기 → “진주에서 서울 가는 표 예매해줘” → 다음 강조를 따라 조회 → 안전 경계에서 종료 → 동의 철회 후 안내 중단 확인.
- 추가 점검: 마이크 거절, 접근성 꺼짐, 음성 인식 실패, 지원되지 않는 명령, 큰 글꼴, 앱 전환과 복귀.
- 기록: 익명 참가자 ID, 기종/OS/앱 버전, 과제, 성공/실패, 막힌 단계, 도움 요청 횟수, 사용자 의견, 수정 내용, 재검증 결과.
- 개인정보: 계정·예약번호·승차권·결제정보를 수집하지 않는다. 실제 구매·결제는 과제에 포함하지 않는다.
- AI의 역할: 기술 QA, 테스트 진행안, 모집·피드백 정리. 실제 사람의 참여와 장애 경험을 대체하거나 테스터 수로 계산할 수 없다.
