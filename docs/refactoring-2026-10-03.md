# 첫 번째 코드 정리

## 도구 선택

Ponytail 원본의 `ponytail-review` 스킬만 프로젝트에 설치했다.
기존 `.kiro/steering/ponytail.md` 및 CUEE 안전 규칙은 유지했다.
Graphify는 관계 탐색에 유용하지만 현재 목표인 불필요한 구현 삭제를 위해
별도의 그래프 생성기와 의존성을 추가하지 않았다.
출처·버전·MIT 라이선스는 `.codex/skills/ponytail-review/`에 기록했다.

## 삭제 근거

새 여행 조건 경로는 `JourneyPlanner`를 사용한다. 옛 데모 시작 분기는
같은 명령의 앞선 분기에서 이미 반환하므로 도달 불가능했다.
서비스 내부의 데모 세션 할당 및 호출을 모두 추적한 뒤 그 경로 전용
재시도, 자동 탭, 자동 스와이프, 노드 클릭·검색 함수, 서비스 음성 인식기를 제거했다.
실제 음성 인식은 `JourneyActivity`에서 계속 제공한다.
역 검색어 자동 입력, 일반 안내 세션, 안전 검사, 메트릭은 유지했다.
공용 데모 도메인 파일은 새 역 검색 안내와 테스트에서 사용하므로 보존했다.
기존 사용자 변경사항, node_modules, 문서, 테스트, 영상은 삭제하지 않았다.
